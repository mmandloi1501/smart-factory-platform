## 📌 The Business Problem

Modern manufacturing organisations struggle with **fragmented data** — production numbers live in one system, sales in another, and recruitment in a third. Leadership teams waste hours consolidating reports instead of making decisions.

**This platform solves that problem** by bringing three critical business functions into a single analytics view — giving operations leaders, business analysts, and HR teams instant visibility into performance across the entire organisation.

## 📊 Platform Modules

### 1. Executive KPI Overview
Four headline metrics visible at a glance:
- Total Units Sold
- Total Production Output
- Average Recruitment Time (days)
- Production Efficiency %

### 2. Sales Performance Analysis
- Units sold trends over time by store and product
- Identifies peak demand periods and sales decline signals
- Interactive filters for store and product selection

### 3. Production & Operations Analysis
- Daily production output by machine and shift
- Machine status tracking — running vs downtime
- Identifies operational bottlenecks and shift efficiency gaps

### 4. Recruitment Pipeline Analysis
- Time spent at each recruitment stage by role and location
- Identifies interview bottlenecks and approval delays
- Supports data-driven hiring strategy decisions

---

## 💡 Key Business Insights Delivered

- **Production efficiency monitoring** — instantly flags underperforming machines and shifts before they impact output targets
- **Sales trend identification** — consistent peaks indicate strong product-market fit while sharp drops signal supply or pricing issues
- **Recruitment bottleneck detection** — extended time in specific pipeline stages reveals interview delays, skill mismatches or approval gaps
- **Cross-functional visibility** — connects production output, sales performance and workforce planning in one view

## 🚀 How to Run Locally

**Step 1 — Clone the repository**
```bash
git clone https://github.com/mmandloi1501/smart-factory-analytics.git
cd smart-factory-analytics
```

**Step 2 — Install dependencies**
```bash
pip install -r requirements.txt
```

**Step 3 — Run the platform**
```bash
streamlit run app/dashboard.py
```
